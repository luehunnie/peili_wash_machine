# 展示广告解禁：用户侧免费、不收打赏（部分推翻 0002 的广告禁令）

2026-09-29 需求 grilling（第二轮）中用户拍板：站点**插入展示广告**，**不收打赏**、不向用户收取任何费用；广告只放在**不影响正常使用的位置**。此决定推翻 ADR-0002 中「不接任何广告」的部分；0002 的非商用基调保留，但其「非商用」边界由本 ADR 重定义。

## 「非商用」的重定义（2026-09-29 议定）

- **用户侧免费**：不向用户收费、不收打赏/捐赠
- **展示广告属可接受的旁路收入**：仅展示型广告，位置不得影响正常使用
- _Avoid_：把「非商用」理解为「零收入」或「可向用户收费」——两者都不对

## Consequences

- 广告上线属**站点更新**，与 CSS 兼容修复、`.tools/` 清理一样，排队在「开发验证」完成后解冻（ADR-0003 关联决定同批）
- 广告位位置、广告网络选型在解冻后另议；0002 记录的现实约束仍有效（此形态站点主流广告网络可接入性差、预期收益极低），选型时须重新评估
- ADR-0002 其余部分（非商用作为对厂商关系的安全姿态）不变
