# 前端视觉基线 · V1 清爽生活蓝（唯一保留稿）

> **2026-09-29 用户定案**：V1（手机端 + 电脑端三断点）为最终视觉基线，其余候选稿 V2–V6 已删除。
> 本文件是 T2 视觉重构的唯一依据。稿内数据为示意（状态随机标注），实际渲染以官方 API 实时数据为准，机器名一律照抄 API 原文。

## 锁定的页面结构（6 点，不再变）

1. **head**：logo + 站名「培黎洗衣速查 / PEILI LAUNDRY」
2. **hero**：一句话标语 + 简介 +「刚刚更新 · 每 30 秒自动刷新」（无状态灯，已否决）
3. **查询面板**：① 选楼栋 chips → ② 选类型 chips + 搜索框（回车滚到机器明细）
4. **洗衣机总览**：全校按楼分组（楼头 = 楼名 + 实时空闲数），每楼一行横滑，楼内楼层低→高（「其它」最后）；机器卡 = 状态灯 + 机器名（照抄原名）+ 楼层 + 占用剩余分钟
5. **机器明细**：文件系统式，楼栋为可折叠文件夹（`<details>`，默认收起），行内结构化标签（楼层 · 类型）+ 名称（照抄原名）+ 状态 + 剩余；搜索命中行高亮
6. **footer**：非官方工具 · 数据来自海乐生活 / 仅供同学们参考，以现场为准

## 设计 tokens（:root 变量）

| 变量 | 值 | 用途 |
|---|---|---|
| --bg / --card | #eef3f8 / #ffffff | 页面底 / 卡片 |
| --ink / --sub / --faint | #17293c / #5c6f82 / #9db0c2 | 主字 / 次字 / 弱字 |
| --line | #e3eaf2 | 描边分隔 |
| --primary / --primary-soft | #2e7df0 / #e5effe | 主色（亮蓝）/ 主色浅底 |
| --idle / --idle-soft | #17a35c / #e2f6ec | 空闲 |
| --busy / --busy-soft | #e8951f / #fdf1dc | 占用 |
| --fault / --fault-soft | #a7b1bc / #f0f3f6 | 故障/维修 |
| --radius | 16px | 卡片圆角 |

状态灯 = 14px 圆点 + 4px 同色柔光圈。字体：system-ui 栈（PingFang SC / Microsoft YaHei）。

## 响应式断点（纯 CSS 媒体查询，<1024px 保持手机单列）

| 断点 | 内容宽 | 布局变化 |
|---|---|---|
| laptop ≥1024px | 976px | hero 与查询面板并排（5fr/6fr 网格）；总览 2 列；明细 2 列文件夹卡；机器行保留横滑，显示 6px 细滚动条 |
| laptopL ≥1440px | 1280px | 总览 / 明细各 3 列；机器卡加宽 140px |
| desktop ≥1920px | 1560px | 列数不变、整页更宽，hero 字号加大 |

**机器行在所有断点保持「每楼一行横滑」**；网格内含横滑行的卡片必须 `min-width: 0`，明细网格 `align-items: start`（收起卡不被同行展开卡拉伸）。

## 状态语义（来自官方 API，不自行推断）

| state | 标签 | 灯色 | 附加 |
|---|---|---|---|
| 1 | 空闲 | 绿 | — |
| 2 | 占用 | 橙 | finishTime 预计结束 →「剩 X 分钟」，≤0 显示「即将结束」；空闲时 finishTime 为 null |
| 3 | 维修中 | 灰 | — |

楼层取 API `floorCode` 原文（含「其它」），**绝不从机器名解析楼层**。
